# 20 — Research Limitations & Epistemic Boundaries

**Document Reference:** RES-LIMIT-001  
**Project:** TRUSTPRINT  
**Version:** 0.1.0-alpha  

---

## 1. Academic & Scientific Honesty Statement

TRUSTPRINT is an open-source hardware verification platform built on principles of scientific rigor. We refuse to make exaggerated or misleading claims regarding what software-driven probing and optical inspection can prove about semiconductor silicon.

---

## 2. Definitive Epistemic Boundaries Matrix

| Claim / Verification Goal | Can TRUSTPRINT Prove This? | Detailed Scientific Rationale |
| :--- | :--- | :--- |
| **"The physical silicon pins match RTL timing behavior at 700 MHz."** | **YES** | Proven via cycle-accurate BIO probing with quantum snap hardware synchronization and waveform comparison. |
| **"The physical chip contains the macro blocks (SRAM, ReRAM, CPU) at published coordinates."** | **YES** | Proven via non-destructive Short-Wave Infrared (~1050 nm) backside optical die micrograph alignment. |
| **"The test results were produced on an authentic Baochip-1x device without post-test tampering."** | **YES** | Proven via hardware-backed Ed25519 cryptographic signatures anchored in on-chip TRNG entropy. |
| **"The test runner cannot access cryptographic signing keys."** | **YES** | Proven via RISC-V Sv39 virtual memory MMU isolation enforced by the Xous microkernel. |
| **"The physical silicon is 100% equivalent to the RTL at the individual transistor level."** | **NO** | Software I/O probing cannot observe unrouted internal nodes or gates without external pin connections. |
| **"There are no dormant hardware trojans hidden in unused standard cell areas."** | **NO** | A hardware trojan that does not alter observable functional pin transitions or macroscopic die dimensions cannot be detected without destructive de-layering and nanometer SEM tomography. |
| **"Optical IRIS inspection resolves sub-micron gate connectivity."** | **NO** | Optical diffraction limits 1,050 nm light resolution to approximately $0.5\ \mu\text{m}$, which is vastly coarser than 22nm transistor gate dimensions. |

---

## 3. Epistemic Labelling Mandate

Every report, chart, and certificate generated by TRUSTPRINT must contain the following standard disclaimer:

> *"TRUSTPRINT verifies observable behavioral conformance, macroscopic die geometry, and cryptographic execution provenance. It does not certify the absence of dormant, non-functional gate-level alterations in unprobed internal logic."*
